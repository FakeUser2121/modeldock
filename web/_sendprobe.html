    Settings

    Global defaults

    Applied to every new chat. Per-chat values live in the chat toolbar and override these.

    Agent types

    Prompt templates the model works under. Edit freely; pick one per chat.

    Allowed outside commands (autonomous mode)

    Exact command strings the agent may run even though they act outside the chat workspace. One per line.

    MCP servers

    Model Context Protocol servers. Their tools become available to the agent in write/autonomous/extend modes.

    Custom tools

    Declarative tools registered in the harness — by you, or by the model in extend mode. Command templates run inside the sandbox; http tools call a URL. Anything can be disabled, edited, or removed here.
